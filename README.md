# 🎮 XO Game (Tic Tac Toe)

A simple console-based Tic Tac Toe (XO Game) implemented in Java using Object-Oriented Programming principles.

---

## 📌 Features

- Two-player mode
- Input validation (prevents invalid moves)
- Detects winner (rows, columns, diagonals)
- Detects draw
- Clean console UI

---

## 🛠️ Technologies Used

- Java
- OOP (Object-Oriented Programming)
- JUnit 5 (for Unit Testing)

---

## 📂 Project Structure

frist.xogame
│── Player.java # Player data (name, symbol)
│── Board.java # Game board logic
│── Game.java # Game flow and user interaction
│── boardInterface.java

---

## ▶️ How to Run

1. Clone the repository:
   git clone https://github.com/MohamedEyara/XO-Game-Tic-Tac-Toe.git
   
2. Open the project in your IDE (IntelliJ / Eclipse)

3. Run the `Game` class

---

## 🎯 How to Play

- Player 1 enters name and chooses (X or O)
- Player 2 gets the other symbol automatically
- Players take turns choosing positions from 1 to 9
- First player to align 3 symbols wins
- If board is full → Draw
